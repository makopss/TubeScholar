# TubeScholar 프롬프트 & 마크다운 템플릿 안내

이 디렉토리는 TubeScholar가 유튜브 영상을 분석하여 학습 노트를 생성할 때 사용하는 **시스템 프롬프트 및 마크다운 출력 양식** 템플릿을 보관합니다.

## 파일 구성
- `system_ko.md`: 외국어 영상 -> 한국어 학습 노트 생성용 (기본 프롬프트)
- `system_ko_native.md`: 한국어 원본 영상 -> 한국어 심층 학습 노트 생성용 (구어체 정돈 및 심화)
- `system_en.md`: 영어 학습 노트 생성용
- `system_ja.md`: 일본어 학습 노트 생성용
- `system_default.md`: 기타 다국어(스페인어, 프랑스어, 독일어 등) 대상 범용 템플릿 (`${TARGET_NAME}`, `${TARGET_LANG}` 지원)

## 사용자 커스터마이징 방법
1. 마크다운 양식(소제목, 표 형식, 퀴즈 유무, 요약 스타일 등)을 변경하고 싶다면 위 마크다운 파일을 원하는 대로 편집하십시오.
2. 프로그램을 재시작하거나 다음 분석 요청 시 수정된 마크다운 템플릿이 즉시 적용됩니다.
3. 사용자 맞춤형 프롬프트는 데이터 디렉토리(`data/prompts/`)에 저장된 파일이 기본 내장 파일보다 항상 우선 적용(Overlay)됩니다.
