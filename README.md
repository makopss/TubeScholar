# 🎓 TubeScholar - 유튜브 LLM 심층 지식 확장 학습기

유튜브(특히 전문 기술, 학술, 교양 등 영문 채널) 영상의 자막을 추출하고, **Google Gemini LLM**을 활용하여 단순 번역을 뛰어넘는 **[오류 교정 + 타임라인별 핵심 요약 + Deep Dive(심화 배경지식 보충) + 전문용어 해설]**을 제공하는 맞춤형 인터랙티브 학습 시스템입니다.

---

## 🌟 주요 핵심 기능

1. **타임스탬프 동기화 스플릿 뷰 (Split-View)**
   - **좌측**: YouTube 플레이어 (되감기, 빨리감기, 배속 조절).
   - **우측**: 마크다운 학습 노트 (타임스탬프 `[03:25]` 클릭 시 해당 영상 위치로 즉시 점프).
2. **단순 번역을 초월한 LLM 심층 지식 확장 (Deep Dive)**
   - **자막 오류 교정**: 자동 생성 자막의 고유명사, 전문용어, 발음 오인식 수정.
   - **지식 보충 해설 (Deep Dive)**: 영상에서 스쳐 지나가는 원리, 이론, 배경 맥락을 친절한 보충 설명 박스로 상세 해설.
   - **핵심 어휘 사전 (Glossary)**: 영상에 사용된 주요 전문 표현 및 맥락 해설 표 제공.
   - **이해도 점검 퀴즈**: 핵심 질문 및 셀프 체크.
3. **영구적인 지식 보관 및 연동**
   - 생성된 모든 학습 문서는 로컬 `data/notes/` 폴더에 표준 `.md` 파일로 영구 저장됩니다.
   - Obsidian, Logseq, Notion 등 기존의 개인 지식 관리 도구에 바로 복사/연동 가능.
4. **채널 단위 영상 탐색 및 일괄 관리**
   - 개별 영상 URL뿐만 아니라 관심 유튜브 채널 URL(예: `https://www.youtube.com/@채널명`)을 입력하여 최근 업로드된 영상 목록을 한 번에 확인하고 선택 변환 가능.

## 🚀 빠른 시작 방법

### 1. 가상환경 패키지 설치
이미 `.venv` 및 `requirements.txt`가 세팅되어 있습니다. 필요 시 아래 명령어를 실행합니다:
```bash
.venv\Scripts\pip install -r requirements.txt
```

### 2. 실행
```bash
.venv\Scripts\python run.py
```
실행하면 브라우저에서 `http://127.0.0.1:8000`이 자동으로 열립니다.

### 3. API 키 설정
- 웹 대시보드 우측 상단의 ⚙️ **설정** 아이콘을 클릭하여 **Gemini API 키**를 입력합니다. (서버의 `.env` 파일에 안전하게 보관됩니다)
- 모델은 기본 `Gemini 2.5 Flash`(추천) 또는 `Gemini 2.5 Pro`를 선택할 수 있습니다.

## 📁 디렉토리 구조

```
serene-hopper/
├── backend/
│   ├── app.py              # FastAPI 메인 서버
│   ├── extractor.py        # 유튜브 자막 및 채널 메타데이터 추출기
│   ├── analyzer.py         # Gemini API 지식 확장 프롬프트 엔진
│   └── storage.py          # 마크다운 노트 및 라이브러리 저장소 관리
├── frontend/
│   ├── index.html          # 스플릿 뷰 대시보드 HTML
│   ├── app.js              # YouTube IFrame 연동 & 타임스탬프 점프 JS
│   └── style.css           # 다크 테마 및 Deep-Dive 콜아웃 스타일
├── data/
│   ├── notes/              # 생성된 마크다운(.md) 문서 보관 폴더
│   └── library.json        # 저장된 영상 메타데이터 인덱스
├── run.py                  # 원클릭 실행 스크립트
└── requirements.txt        # 의존성 목록
```
