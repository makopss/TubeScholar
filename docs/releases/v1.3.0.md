# TubeScholar v1.3.0 — 그룹으로 정리하고, 보관함에서 노트 둘러보기

노트가 많아져도 검색·그룹 버튼·썸네일 목록으로 간단하게 정리하고 둘러볼 수 있습니다.

## 주요 변경

- 검색창 아래에 전체·직접 만든 그룹·자동 분류 이름과 노트 수를 표시합니다. 그룹 버튼을 누르면 바로 이동합니다.
- 검색창 옆 `⋯` 메뉴에서 그룹 관리·새 그룹·휴지통을 엽니다. 그룹 관리에는 별도의 닫기 버튼이 있습니다.
- 새 그룹 입력창은 생성 후에도 유지되며 이름만 비웁니다. 여러 그룹을 연속으로 만들고 `×`로 닫을 수 있습니다.
- 썸네일 왼쪽의 테마에 맞는 체크박스로 노트를 선택합니다. 여러 페이지에서 선택하거나, 그룹 버튼 위로 드래그앤드롭해 한 번에 최대 500개를 추가할 수 있습니다.
- 각 노트의 `⋯` 메뉴에서 열기·그룹 추가·현재 그룹에서 제거·휴지통 이동을 실행합니다.
- 한 번 클릭하면 보관함을 유지한 채 노트가 열립니다. 더블클릭·닫기 버튼·보관함 바깥 클릭으로 보관함을 닫습니다.
- 제목·채널·태그·노트 본문을 검색하며, 본문에서 찾은 결과는 일치 문장을 표시합니다. 자막 본문은 검색 범위에 포함하지 않습니다.
- 저장·수정한 노트를 제목·본문 주요어로 자동 분류합니다. 수학·프로그래밍 등 10개 주제와 기타를 지원하며, 기존 노트도 첫 열람 시 분류됩니다.

## 데이터 보존과 휴지통

- 한 노트를 여러 그룹에 넣을 수 있습니다. 그룹으로 드롭하면 대상 그룹에 추가되며, 기존 그룹에서는 자동으로 제거하지 않습니다.
- 그룹 삭제와 그룹에서 제거는 노트 원본을 보존합니다.
- 휴지통 이동 시 노트·자막·영상·오디오와 그룹 연결을 보존합니다. 복원하면 기존 그룹에서 다시 볼 수 있습니다.
- 휴지통 노트는 먼저 복원한 뒤 열거나 수정할 수 있습니다. 영구 삭제는 별도 확인 후 실행되며 되돌릴 수 없습니다.
- 공유 영상 사본은 마지막 연결 노트를 영구 삭제할 때 정리합니다. 원본 영상 파일은 변경하지 않습니다.
- 휴지통 자동 삭제 기한은 없으며, 영구 삭제 전까지 저장 공간을 사용합니다.
- 오디오 정리 시 ID 앞부분이 같은 다른 노트의 파일을 보호하고, 영구 삭제의 메타데이터 저장 실패 시 메모리 목록과 파일을 보존하도록 보완했습니다.

## 범위

자동 분류는 추가 API 호출 없는 로컬 키워드 방식이며, 의미를 추론하는 AI 분류가 아닙니다. 직접 만든 그룹을 자동으로 바꾸지 않습니다. 플레이리스트·폴더 단위 일괄 분석은 이번 버전에 포함하지 않습니다.

## English

The library now combines search, thumbnail rows, text-only group chips with note counts, and per-note `⋯` menus. Create several groups without reopening the form; select notes using checkboxes beside thumbnails or drop them onto a manual group chip. Notes can belong to multiple groups.

A single click opens a note while keeping the library available. Double-click, use Close, or click outside to dismiss it. Search covers titles, channels, tags and note text. Automatic topics use local keywords without additional API calls and preserve manual groups.

Trash retains notes, subtitles, audio, managed videos and group membership until restoration or confirmed permanent deletion. Shared video copies remain until their last note reference is removed. Audio cleanup protects other notes with overlapping ID prefixes, and a failed metadata save during permanent deletion leaves the cached library and files intact.

Playlist/folder batch analysis and semantic AI classification are outside this release.

All 104 offline regression tests passed. The Windows bundle and installer compiled successfully. Packaged startup, exact frontend asset hashes, transcript persistence, saved media and Range delivery, automatic topics, group operations, Trash, restore and permanent deletion were checked. A short live edge-tts generation and saved audiobook restoration passed. Browser checks against the packaged app covered selection, counts, drag-and-drop and note browsing/closing. Installing into the user's Windows environment, speaker listening and live Gemini/Groq quality were not tested.
