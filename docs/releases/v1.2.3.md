# TubeScholar v1.2.3 — 로컬 분석 통합과 영상·노트 함께 열기

로컬 영상 모달을 **분석 진행 / 프롬프트 복사** 두 버튼으로 정리했습니다. 보관 노트를 다시 열면 영상도 함께 재생되도록 원본 영상 사본을 앱 데이터에 보관합니다.

## 주요 변경

- 첨부 자막이 있으면 음성 인식 없이 해당 자막을 Gemini에 전달합니다.
- 자막이 없으면 Groq 키가 등록된 경우 Groq 전사 후 Gemini가 노트를 생성하고, Groq 미등록 또는 전사 실패 시 Gemini가 추출된 음성을 분석합니다.
- 프롬프트 복사는 사용할 자막이 준비되면 활성화됩니다. 첨부 SRT/VTT나 저장된 전사 자막을 이용하며, 노트 생성 성공을 기다릴 필요가 없습니다. 실제 생성 자막이 없는 경우에는 비활성화됩니다.
- 영상은 앱 데이터의 `videos/`에 보관되므로 원본 이동이나 앱 재시작 후에도 보관함에서 영상·자막·노트를 함께 열 수 있습니다.
- 구버전 노트에는 **원본 영상 연결**을 제공합니다. 원본 파일을 한 번 연결하면 이후 자동으로 복원됩니다.
- 동일 파일을 여러 노트에서 공유하며, 노트 수정·재작성·구독 AI 답변 저장 시 연결을 유지합니다. 마지막 연결 노트를 삭제하면 보관 사본을 정리합니다. 원본 파일은 변경하지 않습니다.
- 구간 재생(Range), 업로드 용량 제한, 취소 처리와 관리 폴더 밖의 파일 접근 차단을 적용했습니다.
- 한국어·영어 안내 및 README를 갱신했습니다.

## 사용 시 참고

영상 사본은 저장 공간을 사용합니다. 브라우저가 지원하는 영상 코덱이 필요합니다. 이전 버전은 분석용 임시 영상을 삭제했으므로 기존 노트의 영상을 자동으로 찾아낼 수 없으며, 한 번 재연결해야 합니다.

- 백엔드 회귀 테스트 35개, 프론트엔드 회귀 테스트 9개 통과
- 실제 브라우저에서 새로고침 후 보관 영상·자막 복원 및 기존 노트 영상 재연결·재생 확인
- 첨부 자막 경로의 음성 인식 생략, 노트 실패 후 영상·자막 유지, Gemini 음성 경로 영상 보관 확인
- 파일 중복 제거·교체·삭제, 복사 취소 시 임시 파일 정리, Range 및 파일 접근 제한 검증
- 새 실행 파일의 기동, 정적 화면, 자막 보관, 영상 연결 및 Range 재생 검증

AI 서비스는 회귀 테스트에서 모의 호출했습니다. 외부 Gemini·Groq 서비스의 실시간 가용성이나 응답 속도를 검증한 결과는 아닙니다.

## English

This release unifies local analysis into **Start Analysis** and **Copy Prompt**, automatically choosing supplied subtitles or audio processing. Groq transcribes when configured; otherwise, or after a transcription failure, Gemini analyzes the extracted audio.

Videos are now retained alongside saved notes and reopen with subtitles after restart. Older notes support a one-time **Reconnect Original Video** action. Managed copies are deduplicated, preserved across note edits and removed when their final linked note is deleted. Playback uses HTTP Range and requires browser-supported codecs.

Prompt copying requires real subtitles rather than successful note generation. All 44 offline regression tests, browser restoration checks and packaged-app checks passed. External AI availability was not tested.
