# TubeScholar v1.2.2 — 로컬 영상 분석 안정화

로컬 영상 분석이 오래 대기하거나 중단 후 이전 결과가 다시 나타나는 문제를 개선했습니다. 전사된 자막을 먼저 보관하므로 노트 생성이 실패해도 재업로드·재전사 없이 이어갈 수 있습니다.

## 주요 변경

- 분석 작업별 취소·진행 상태를 분리하고, 이전 요청·폴링 결과가 새 분석 화면을 덮어쓰지 않도록 수정했습니다.
- FFmpeg, Groq 음성 인식, Gemini 업로드·생성에 취소와 시간 제한을 적용했습니다. 전체 분석 제한 시간은 업로드를 포함해 기본 600초이며 환경 설정으로 조정할 수 있습니다.
- Groq 전사 결과와 입력 자막을 노트 생성 전에 보관합니다. 실패·취소 후 보관함의 해당 항목을 열고 **노트 재작성(🔄)** 을 선택하면 저장된 자막으로 재시도할 수 있습니다.
- 자막 파일 없이 분석 버튼을 눌렀을 때 음성 분석으로 연결하고, 진행 단계를 서버 상태에 맞춰 표시합니다.
- 생성된 SRT가 없거나 유효하지 않으면 이를 안내합니다. 학습 노트의 요약문을 원문 자막으로 대신 저장하는 동작을 제거했습니다.
- 브라우저 및 업로드 수신 단계에서 용량을 검사하고, 오류·취소·저장 완료 상태와 진단 로그를 보완했습니다.
- Python과 네이티브 wheel의 호환성을 빌드 전에 검사하며, 브라우저를 열지 않고 별도 데이터 폴더에서 패키지를 검증하는 스크립트를 추가했습니다.
- 한국어·영어 README에 설치, 복구, 설정 및 검증 방법을 반영했습니다.

## English

This release improves local video analysis, cancellation and recovery:

- Request-scoped jobs prevent late results from overwriting a newer analysis.
- Cancellable FFmpeg, Groq and Gemini operations use bounded timeouts, with a configurable 600-second total deadline.
- Completed Groq transcripts and imported subtitles are saved before note generation and can be reused with **Regenerate note** after failure or cancellation.
- Missing or invalid generated subtitles are reported explicitly; note summaries are never substituted for dialogue.
- Upload limits, progress reporting, diagnostics and native-wheel build checks are improved.
- All 34 offline regression tests passed, together with real FFmpeg extraction and packaged-app startup/persistence checks. External AI service availability was not tested.
